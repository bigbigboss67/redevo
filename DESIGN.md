# Design System: Aethel Apex // I LOVE BOSNIA Enterprise OS

## 1. Visual Theme & Atmosphere
A restrained, high-contrast, editorial architecture studio interface. Tailored for both high-glare mountain daylight (crisp slate-50/white cards with fine 1px slate-200 borders) and executive evening boardroom sessions (obsidian #090B0E base with warm amber-500 typography).
- **Density:** 7 (Structured cockpit, readable by non-professionals).
- **Variance:** 6 (Asymmetric split-screen topographic maps and 120-plot matrix).
- **Motion:** 5 (Spring physics on drawers and modals; perpetual micro-pulses on live IoT sensors).

## 2. Color Palette & Roles
- **Canvas Daylight** (#F8FAFC) — Glare-resistant field tablet background
- **Obsidian Dark** (#090B0E) — Boardroom presentation background
- **Card Surface** (#FFFFFF / #11141D) — High-contrast container fill
- **Text Main** (#0F172A / #F1F5F9) — Slate-900 high legibility
- **Text Muted** (#64748B / #94A3B8) — Slate-500 secondary context
- **Border Subtle** (#E2E8F0 / rgba(255, 255, 255, 0.08)) — 1px structural dividing lines
- **Brushed Amber** (#E5A93C) — Singular primary accent for active states, CTAs, and selected letters (Saturation: 78%)
- **Status Emerald** (#10B981) — Verified milestones and biometric turnstile active
- **Status Rose** (#F43F5E) — Heart '♥' Resort and 24h defect punch pins
- **Status Cyan** (#06B6D4) — Building 'I' Clinic and BIM Digital Twin point cloud

## 3. Typography Rules
- **Display / Headlines:** Plus Jakarta Sans — Track-tight (-0.02em), bold weight hierarchy.
- **Data / Metrics / Plot IDs:** JetBrains Mono — High-density financial figures, coordinates, and plot tags (e.g., K-018, €97,000,000).
- **Banned:** No Inter, no generic serif fonts in dashboards, no uppercase shouting headers.

## 4. Component Stylings
- **Buttons:** Tactile feedback with active translateY(-1px). No neon glows.
- **Cards:** Double-bezel hardware styling with smooth 1.5rem rounded corners. 
- **Navigation:** Clear descriptive text labels with explicit functional sub-captions (e.g., "1. Master Cockpit // GDV, Cash & Portfolio KPI").
- **Workflow Guide:** Prominent 4-step progressive numbered path with immediate action buttons.

## 5. Anti-Patterns (Strictly Enforced)
- No emojis in UI buttons or telemetry.
- No pure black (#000000) surfaces.
- No neon purple/cyan AI glow borders.
- No generic template placeholder names.
- No broken image links (all photos mapped locally to assets/images/).
